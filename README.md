# Buscador y Visor de Documentos Técnicos

Aplicación web para cargar documentos técnicos (TXT, PDF, Markdown) con metadatos,
procesarlos e indexarlos de forma asíncrona, buscarlos por texto completo con
resaltado y paginación, y visualizarlos en la aplicación con notificaciones de
estado en tiempo real.

> Proyecto en construcción. Las instrucciones de ejecución, pruebas y despliegue
> se completan en las siguientes fases. Consulta [`CLAUDE.md`](./CLAUDE.md) para
> el alcance y el plan de trabajo.
